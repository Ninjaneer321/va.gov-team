# Copilot Chat Research System: Usage Tracking

**Purpose:** Track adoption and usage of the research discovery system after launch.

**Review frequency:** Weekly for the first month, then monthly

---

## How We Track

### Via Slack (#research-ops)
- Questions about the system
- Positive vs negative feedback
- Common confusion points
- Feature requests
- Success stories

### Via GitHub
- Issues filed with `copilot-research` label
- Bug reports
- Feature requests
- Enhancement requests

### Direct Feedback
- DMs from researchers
- Mentions in research community meetings
- Informal conversations
